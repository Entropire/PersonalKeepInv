# PersonalKeepInv

PersonalKeepInv allows every player to have their own Keep Inventory setting, independent of other players.

Server administrators can also configure a default Keep Inventory setting for new players. This default reuses Minecraft's built-in `keepInventory` gamerule.

## Commands

| Command | Description |
|---|---|
| `/keepinv` | Shows your personal Keep Inventory status |
| `/keepinv on` | Enables your personal Keep Inventory |
| `/keepinv off` | Disables your personal Keep Inventory |
| `/keepinv default` | Shows the default Keep Inventory status |
| `/keepinv default on` | Enables the default Keep Inventory |
| `/keepinv default off` | Disables the default Keep Inventory |

## Default Keep Inventory


The default setting is based on Minecraft's built-in `keepInventory` gamerule. This gamerule is reused to determine the default setting assigned to players when they join for the first time.
